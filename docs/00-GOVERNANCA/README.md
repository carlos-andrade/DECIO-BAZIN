# 00 — Governança

Esta pasta contém as regras de organização, rastreabilidade, fontes e controle metodológico do projeto DECIO-BAZIN.

## Regra central
A pesquisa deve separar rigorosamente:

1. fonte primária;
2. fonte secundária;
3. interpretação;
4. adaptação contemporânea;
5. resultado quantitativo/backtest.

Nenhuma adaptação moderna deve ser apresentada como sendo de autoria de Décio Bazin sem evidência documental.
