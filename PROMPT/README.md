# PROMPT

Pasta destinada aos prompts oficiais utilizados para orientar a pesquisa documental, metodológica e quantitativa sobre Décio Bazin.

## Prompt oficial

- `PROMPT-MESTRE-DECIO-BAZIN-NO-MERCADO-FINANCEIRO.md` — prompt mestre criado para conduzir a pesquisa sobre Décio Bazin, sua carreira, o livro *Faça Fortuna com Ações — Antes que seja tarde*, o método de dividendos/preço/yield, comparações metodológicas, formalização quantitativa, adaptações contemporâneas e backtests.

## Regra

O prompt orienta a pesquisa, mas não substitui as evidências documentais. Afirmações históricas e atribuições metodológicas devem ser verificadas nas fontes correspondentes.
